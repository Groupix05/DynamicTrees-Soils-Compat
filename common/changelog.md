  - Rooty Silt

  - Rooty Earthen Clay
  - Rooty Grassy Earthen Clay
  - Rooty Grassy Permafrost
  - Rooty Grassy Sandy Dirt
  - Rooty Grassy Silt

### Version 1.0.3

- Added support for Blooming Nature soils:
  - Rooty Laterit
  - Rooty Mossy Laterit
- Added support for Immersive Weathering soils:
  - Rooty Mulch Block
  - Rooty Nulch Block
- Added support for Lunarnether soil:
  - Rooty Lunar Dust
- Added support for Minecolonies soil:
  - Rooty Composted Dirt
- Added support for Supplementaries soil:
  - Rooty Planter
- Added support for Teletubbies soil:
  - Rooty Full Grass
- Changed Unearthed rooty soil IDs to drop the `_unearthed` suffix (e.g. `rooty_overgrown_granite_unearthed` → `rooty_overgrown_granite`).
- Vanilla Rooted Dirt can now spread to Immersive Weathering Rooted Grass Block.

### Version 1.1.0

- Added missing blockstates for the 1.0.3 soils (Mulch Block, Nulch Block, Lunar Dust, Composted Dirt, Planter, Full Grass).
- Removed support for Blooming Nature soils:
  - Rooty Laterit
  - Rooty Mossy Laterit
